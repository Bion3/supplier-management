# 货代知识库

入口：`/knowledge.html`。与供应商管理和客户CRM共享现有Supabase登录。

## 使用流程
1. 选择现有航线分类，或创建具体航线（起讫地、节点）。
2. 新增条目，选择航线和关联供应商；类型包括航线档案、操作SOP、报价、单证要求、异常案例。
3. 保存后上传原始资料。支持PDF、Word、Excel、CSV、文本、图片及EML，单文件最大20MB。
4. 编辑条目填写内容、适用范围、来源及有效期。已核实条目必须填写内容与核实依据。
5. 按航线、状态或全文搜索。有效期之后自动显示已过期；保存修改保留旧版本，过时版本提交会被拒绝。

## 数据与访问
- 表：freight_knowledge_routes、freight_knowledge_entries、freight_knowledge_documents、freight_knowledge_versions。
- 原件：私有freight-knowledge桶，下载使用60秒签名链接。
- RLS沿用supplier_hub_access授权对象；不允许匿名访问。
- 无数据删除入口，版本表不允许客户端更新/删除。版本记录供业务回溯，不作为不可伪造审计台账。
- 附件登记失败时尝试清理文件，清理失败显示路径供管理员处理。
- database/freight_knowledge.sql是已执行迁移的版本记录，不要重复运行。

## 当前边界
第一版为人工整理和检索，未接入PDF/Office解析、OCR或AI提取。文件名及已整理内容可搜索，原件内部正文不会自动进入检索。ChatGPT对话上传不会自动同步至此系统。

## 验证
10项模型测试、构建和语法检查通过；真实数据库验证授权写入、更新、历史快照、旧版本冲突和未授权身份不可读，测试写入已回滚。浏览器API模拟测试另行执行；不能替代真实登录上传验证。
