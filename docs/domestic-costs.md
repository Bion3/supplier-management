# 国内采购价库

入口 `/rates.html`，测算 `/cost.html`。沿用供应商系统登录和授权。

采购价按提货（门点到集货仓）和干线（集货仓到装箱仓）区分。报价记录关联供应商，并保存始发区域、目的仓、币种、规则、有效期、来源和备注。更新采用插入新版本、关联 supersedes_id 的方式；旧记录保留。

规则支持实际CBM、吨、吨价/方价金额取大、按每段重抛比折算、固定票价和体积/重量双条件阶梯。最低运费先作用于运费，送货费另加或标记已含。阶梯按整票套档；未匹配或重叠提示待确认。

参考附件427条暂存为草稿，保留raw_source原始数据与行号。原表零金额转为空待确认，轻货/重货卖价不映射到采购价。供应商、计价规则、最低收费与重抛比需要确认后保存新版本，草稿不进入测算选择器。

测算选择采购价后将报价ID、供应商、规则与金额复制到测算输入快照。提货/干线分别替代对应手动费，铁路继续使用自身重抛比。改变区域筛选清空相关已选采购价。历史测算使用其保存的快照，价格库更新不重写历史成本。

首版区域匹配为文字包含搜索，仓库名称需要使用一致的名称。采购价库每页20条。当前支持提供附件的预览与确认录入，后续新Excel文件上传解析不在本版范围内。

验证：45项Node测试通过；静态构建及JavaScript语法检查通过；数据库授权写入事务测试回滚，未授权读取返回零行。线上完整登录后交互需真实登录会话验证。

## 自动测算

测算页仅录入起始地、目的地、件数、毛重、体积。采购价库负责维护国内价及 `/rail-rates.html` 的铁路采购方案。方案含起运站、目的站、有效期、整柜成本/外配单价、重抛比、折算分母和默认利润参数。

自动按目的地匹配有效铁路方案，再将国内提货和干线连接到该方案的起运站。省市层级采用逗号分隔的节点匹配；明确支持汉堡/Hamburg、西安/Xian别名。缺段保留待询价，不套默认参考金额。提货直达装箱仓时不重复增加独立干线。多条国内路径优先费用完整、再按已知采购金额选择；多个铁路方案供切换。新旧采购版本按supersedes_id排除旧版，历史测算保存原始快照。件数用于保存业务信息，当前采购计价按重量、体积、票及阶梯。

自动匹配新增5项测试，完整回归50项测试。
