# 整箱铁路采购价格

入口：采购价格中心 → 国际运输 → 整箱铁路运费（`fcl-rail.html`）。

每条记录对应一个供应商、起终站、班列服务、箱型、SOC/COC及计价单位。
`2×20尺`使用“组”，不是单个20尺集装箱价格。币种沿用原表，未自动换汇。
站到站、国内段、铁海联运和范围待确认的分拨报价分开标识。

`freight_fcl_rail_rates`仅开放原供应商系统授权用户的读取和新增。
编辑、批量确认和停用均新增版本，`supersedes_id`指向旧版本，禁止直接更新和删除。
唯一索引防止同一原始单元格重复导入及同一旧版本产生并行后继。

## 原表导入

`scripts/prepare_fcl_import.py`读取郑州整柜报价工作表，以及长安号PDF的第1–5、7–9页。
需要本地Python的openpyxl和pdfplumber，生成JSON草稿，不自行写入数据库。
传入两个文件及已核实的供应商ID。导入端按JSON批量插入并校验总数和来源分布。
数字单元格按独立箱型拆开；斜线、空白、横线不当作零报价。
PDF公式报价保留原文且价格为空；点千位分隔符保留规范化说明。
郑州第28、43行空白币种保持待确认。原表月份不能直接替代明确的有效期。
53条境外分拨报价未明确起运范围、箱型、SOC/COC，保留为待确认，不能直接叠加为后程费用。

利润字段仅保存预设，不进入采购单价。新板块尚未接入单票整箱成本测算。
