# 飞书邮件工作台

入口 `/mail.html`，与CRM共用Supabase登录。唯一发信账号为 `benjamin@eurasiago.com`，使用飞书 `smtp.feishu.cn:465`（SSL）。SMTP凭据只在Vercel Function读取，不进入前端、数据库或代码仓库。

## 最后配置

1. 在飞书邮箱设置中启用第三方邮箱客户端登录，生成专用密码。参见 https://www.feishu.cn/hc/zh-CN/articles/902478147400
2. 在本项目Vercel Environment Variables添加 `SMTP_PASSWORD`，类型选择Secret，仅Production。
3. 重新部署Production让新变量生效。
4. 登录邮件工作台，选择“发送测试邮件到自己邮箱”，预览后确认发送，核对飞书收件箱。

## 当前功能

- 维护、开发模板与变量替换，保存新模板。
- 搜索邮箱/公司/线路、按客户状态筛选；核实后选择收件人。
- 相同邮箱去重；停止联系覆盖同一邮箱所有已有档案，服务器也会检查。
- 每批最多10封，逐封预览、保存草稿、明确确认发送；每封独立收件人。
- 数据库原子领取草稿，避免重复点击并发发送；每日最多50封（上海时区）。
- 记录草稿、处理中、服务器已接受、失败、结果不确定；手动更新回复状态。

SMTP服务器接受不等于最终送达；当前不自动读取飞书回复、不追踪打开率、不自动处理退信，不配置定时群发。结果不确定和处理中的记录需要核对飞书已发送邮件，不能直接自动重试。失败需检查原因后重新建立草稿。

权限来自 `freight_mail_access`，初次迁移复用现有供应商账号范围。模板与记录使用RLS；所有发送请求验证Supabase用户及邮件权限，收件人需有效且允许邮件联系。

部署在Vercel `/api/mail` Node Function，依赖版本与package-lock固定。测试用传输替身，不产生真实邮件。数据库测试事务全部回滚。
