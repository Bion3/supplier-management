# 飞书邮件工作台

入口 `/mail.html`，与CRM共用Supabase登录。唯一发信账号为 `benjamin@eurasiago.com`，使用飞书 `smtp.feishu.cn:465`（SSL）。SMTP凭据只在Vercel Function读取，不进入前端、数据库或代码仓库。

## 最后配置

1. 在飞书邮箱设置中启用第三方邮箱客户端登录，生成专用密码。参见 https://www.feishu.cn/hc/zh-CN/articles/902478147400
2. 在本项目Vercel Environment Variables添加 `SMTP_PASSWORD`，类型选择Secret，仅Production。
3. 重新部署Production让新变量生效。
4. 登录邮件工作台，选择“发送测试邮件到自己邮箱”，预览后确认发送，核对飞书收件箱。

## 当前功能

- 维护、开发模板与变量替换，保存新模板。
- 搜索邮箱/公司/线路、按客户状态筛选；核实后选择收件人。
- 相同邮箱去重；停止联系覆盖同一邮箱所有已有档案，服务器也会检查。
- 每批按设置数量发送（默认10封），逐封预览、保存草稿、明确确认发送；每封独立收件人。
- 数据库原子领取草稿，避免重复点击并发发送；每日上限按设置执行（默认50封，上海时区）。
- 记录草稿、处理中、服务器已接受、失败、结果不确定；手动更新回复状态。

## 收件人操作

地区、客户类型、客户状态、验证状态、是否允许联系和分组可组合筛选。未填地区时从历史地址推断，仅作为筛选候选并在列表标注；手动地区优先，支持批量修正，同步到CRM公司档案。

联系方式支持多个持久分组，用逗号分隔名称批量加入或移出。可选择本页、全部筛选结果或跨页勾选，选择不等于发送授权。批量标记有效只记录用户已核实的结论，不是自动邮箱探测。

顶部操作栏随滚动保留，预览弹窗的草稿和发送按钮也放在顶部。超过设置的每批数量时，每次预览该数量的邮箱，实际成功提交后从选择中移除同一邮箱的记录，余下继续保留。停止联系与未验证的选择会阻止预览，不会静默忽略。

飞书连接配置和测试邮件入口收进“设置”弹窗，日常列表不展示。表头复选框全选或取消本页，跨页已选记录保持；“选择筛选结果”选择所有筛选匹配记录。批量验证可设为有效、待核实、失效；批量邮件联系可设为允许或停止，同一邮箱在其他客户档案中的记录也会同步。

SMTP服务器接受不等于最终送达；当前不自动读取飞书回复、不追踪打开率、不自动处理退信。结果不确定和处理中的记录需要核对飞书已发送邮件，不能直接自动重试。失败需检查原因后重新建立草稿。

权限来自 `freight_mail_access`，初次迁移复用现有供应商账号范围。模板与记录使用RLS；所有发送请求验证Supabase用户及邮件权限，收件人需有效且允许邮件联系。

部署在Vercel `/api/mail` Node Function，依赖版本与package-lock固定。测试用传输替身，不产生真实邮件。数据库测试事务全部回滚。


## 发送规则和定时任务

“设置”中可修改每批数量（1–100）、每日上限（1–1000），每批数量不能大于每日上限。每日上限由数据库统一执行，所有授权账号共享上海时区当天额度。

可保存立即发送或指定日期时间作为预览默认值，时间按北京时间（UTC+8）填写。保存设置不创建任务：选择客户后仍需预览并点击“确认定时发送”。本次时间也可在预览顶部调整。已提交记录显示“待定时发送”，可在记录中取消，取消后恢复草稿。

后台使用Vercel Queues，页面关闭后仍能到期执行；超过队列七天保留期的时间通过六天以内的分段唤醒续接。到期再次检查账号授权、联系人有效状态及同邮箱停止联系记录。达到当天限额时顺延到上海时区次日00:01。多个任务同时到期时，通过数据库原子领取避免超额及重复发送。

生产环境需设置Secret类型的 `MAIL_WORKER_SECRET`，其SHA256摘要存于私有数据库凭据表；工作进程只能通过限定RPC处理定时邮件，不持有通用数据库管理员密钥。运行迁移 `database/mail_schedule.sql`，并部署 `api/mail-queue.js` 的队列触发器。后续部署应保持摘要与环境变量一致。

SMTP结果不确定时不自动重发；发送后记录写入异常时，后续回调等待十分钟再标记为结果不确定，避免重复联系客户。自动化测试使用传输替身，不验证飞书实际送达。
