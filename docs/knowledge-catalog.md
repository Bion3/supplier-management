# 站点、资料版本与本地原件

知识库追加来源目录与站点目录。来源每个版本独立一行，新增版本用supersedes_id关联，历史来源不自动失效。知识条目保留适用站点、整箱/拼箱/进口、来源、生效时间、替代关系和修改说明；原有编辑历史继续由数据库触发器保留。

本地位置为用户手工登记的本机文件位置，仅保存字符串。网页可复制路径，但不会访问、移动或上传用户电脑文件。当前上传的原件没有写入Supabase文件桶，也没有把代理scratch路径冒充用户本地路径。

历史站码以文本保留，来源不同、代码类型未确认、占位值、国家/区域和港口均标明，不作正式运单校验。当前资料为待审核或历史已过期条目。系统不自动将来源最新上传日期视为生效日期，也不自动应用历史禁运个案、计费参数或费用。

同一条规则的新正式版本可以新增条目并选择替代旧条目；适用范围不同的规则并列保存。界面显示替代关系，不跨站点自动覆盖。

导入明细由本次资料提取后写入数据库，不把客户文件、原文、价格或站码写入公开Git仓库。数据库中的import_key用于导入幂等；具体文件名与单元格出处保留于来源和条目。
