欧洲与中欧铁路怎么找客户

先用官方统计筛选“国家 + HS 编码 + 月份”的市场，再用英国 HMRC 企业名录或有明确来源的逐票记录寻找企业，通过官网、ENF 和展商目录补全身份及联系方式。

英国可查企业贸易活动。 HMRC 可查企业名称、地址、进出口身份、商品与活动期间，但不提供具体往来国家、交易金额、数量或客户名单。因此不能仅凭 HMRC 名录标记“从中国进口”或“有铁路需求”。

欧洲不同国家的企业信息开放范围不同；商业平台中的欧洲企业也可能来自交易对方的镜像记录。中欧铁路覆盖应单独确认，不能用美国海运提单代替铁路货量。发货人、收货人可能是贸易公司、货代或代理。

与 ENF、展商目录及客户资源相互验证

采集时按来源及同名、同地区客户去重，法律实体身份仍待核实；模糊名称不自动合并。完整跨源证据匹配尚未接入。已有客户可在客户资源中查看来源与跟进，不覆盖既有分类和联系方式。

核实目标交叉证据应记录的结论
是否为同一家企业原始企业名、地址 + 官网法律名称、注册号、注册地址名称匹配 / 疑似匹配 / 已确认匹配；仅名称相似不合并
是否经营目标产品ENF 分类 + 官网产品 + 展商介绍 + 交易商品描述产品匹配程度；保留 HS 版本与描述，不仅凭编码判断
是否有近期贸易活动企业活动名录或逐票记录 + 最新活动日期来源覆盖内有活动；不把未查到记录标记为无进出口
是否存在交易关系同条原始记录中的双方名称、日期、货物与记录 ID记录内关系；确认前不标记为直接采购关系
是否值得开发产品、地区、近期活动 + 经核实的官网和联系方式联系优先级，结合现有 CRM 跟进
是否适合中欧铁路中国—欧洲交易线索 + 货物适运性 + 实际运输资料或客户确认铁路潜在线索 / 已确认铁路需求，分开记录

同一原始提单在多个平台出现，只算一条记录。 记录供应商与原始来源，优先按原始记录 ID 去重；无 ID 时用双方、日期、单号和货物辅助核实，不把三个平台当作三份独立证据。

宏观镜像统计只用于比较市场方向，不验证单家企业货量。FOB / CIF、时间差、转口和统计口径会导致双方数字不同。

来源边界与 API 接入检查
  • 美国 ACE 报表需要账号及指定角色；它与面向公众的海运舱单数据是不同渠道。
  • 不能统一认定“某国全部舱单公开”。巴西官方统计不提供可识别企业的贸易信息及相应名单；商业记录需另核实来源。
  • 宏观镜像：贸易对方报告的汇总统计。企业镜像：对方记录中出现的企业。两者都不代表本国完整企业数据库。
  • API 接入前，确认目标国家、进出口方向、期间、运输方式、双方字段、更新日期、额度及 CRM 保存授权。
  • 企业授权提供自身报关资料，与未经授权泄露监管资料分开处理；出现中国企业名称不等同于数据来自中国监管内部。
